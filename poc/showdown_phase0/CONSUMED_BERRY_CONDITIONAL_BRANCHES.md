# Gate B / PR #170 — 消費済みきのみの確定観測を条件付き仮説へ反映

## 目的と条件

PR #169の限定合成局面（現在HP・7能力ランク・壁/残ターン、地形/設置物/現在タイプの確定、未対応の効果履歴を拒否）に対して、**観測された「現在の持ち物なし」と「以前に消費したきのみ」**を独立の事実として取り扱う。従来は現在の道具を空と観測すると、初期道具がオボンのみの候補Bは開始時不一致として除外されていた。今回、持ち物の初期状態と現在状態を区別して、候補の観測整合性を検査する。

- `opponent_consumed_item`と`opponent_item=""`の両方が観測ソース（`SYNTHETIC` または検証済み `GAME_OBSERVED`）で存在する場合のみ試す。**持ち物不明や現在も所持しているケースは拒否**。
- 対象を固定Champions持ち物マスターの`区分=きのみ`かつ`発動/消費=対戦中1回`の品に限定する。**こだわりスカーフ・たべのこし等の非消費品、はたきおとすによる除去は、消費イベントと誤分類しない**。手元の4つの合法な固定候補ではオボンのみBが該当。
- `makeCandidates`には初期所持品が残る原型の相手型仮説を渡し、コピーした各候補についてだけ元の持ち物が観測消費品と一致することを検査。合致する候補のみ**現在の持ち物が空という状態**へ変更し、他の確認済みHP・能力段階・壁状態と一緒にシリアライズ往復、条件付き1ターン分岐を行う。
- 元の観測事実と各候補の元Battleを変更しない。観測に合致しない相手型を無理に変換せず、マスターに存在する別のきのみでも初期所持候補が0件なら`UNSUPPORTED`へ倒す。
- **きのみが発動したターンを再現しない**：回復量・発動条件・最後の持ち物・技PP・HP回復前の値・内部RNG・他ターンでの道具発動・消費行動ログをShowdownの合成状態から真の履歴へ遡及しない。現在HPは観測値のまま、`item_history_scope=CONDITIONED_EMPTY_ITEM_ONLY_NO_CONSUMPTION_EFFECT_OR_LOG_REPLAY`で区別する。
- 出力は常に`PROVISIONAL_CONDITIONAL_SYNTHETIC`、Gate A `UNKNOWN`／Gate B `UNSUPPORTED`／本番統合 `NO_GO`。一つの固定候補に絞れても真の型・完全な実戦履歴を確定したとは言わない。

## レビュー・テスト

- オボンのみ消費と現在未所持の組で、候補Bのみ条件付き継続し、HPは観測した70のまま、ハッシュと継続結果が再実行で一致する。
- 道具が未知・まだ所持されているケース、非消費品（こだわりスカーフ、たべのこし）、「マスターでは消費するが4候補に所持者不在」（オレンのみ）は拒否。
- マスターに存在しない道具、履歴が不明な別効果、偽装した観測ソースは既存/追加の監査で拒否。
- LinuxとWindows native Nodeの隔離CIで、新旧Gate Bテストをともに実行する。Windows desktopは別途最新HEADのワークフローで確認。

## 未解決

メガ後の履歴／行動キュー／RNGの復元、相手技・PP・特性・APの同時不確実性、および実ゲームの途中観測からの完全な状態構築は引き続き未達。きのみ消費の**ゲーム内発動工程**の計算は本PRの検証範囲ではない。既存LIVE判断・固定マスター・ユーザーの非公開Goldenは変更しない。
