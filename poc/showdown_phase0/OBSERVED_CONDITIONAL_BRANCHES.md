# Issue #139 / Gate B — 観測済み途中状態からの条件付き複数仮説（限定PoC）

## 目的（GO判定ではない）

固定Showdownの選出3匹・初手の合成Battleから、**開始時のHP・能力変化・壁状態を勝手に使ってしまう**既存Gate Bの限界に対して、ゲーム画面等で**確定できた値だけ**を候補Battleへ条件付き反映する。未知の相手技・持ち物・特性・AP・内部RNG・行動履歴はそれぞれの仮説として保持し、真のゲーム状態には昇格させない。

既存`partial_observation_probe.cjs`は26件の対象機構で`UNKNOWN`／`INFERRED`と一致候補の区別を検証済み。一方で、中途HPや積みランクが観測されて開始時のフルHPと異なる場合、既存の合成Battleはそのままでは継続できない。PR #169 は**別の限定されたconditioning実験**として`observation_conditioned_branch_probe.cjs`を追加する（既存26件の判定・Gate A/B集計・採用レポートは変更しない）。

### 実装した限定条件

- 登録6→選出3を使った固定・合法な候補A/B/C/Dを生成し、観測ソース（`SYNTHETIC`／ユーザー検証済みの`GAME_OBSERVED`ラベル）の**相手整数HP・7段階の能力変化・壁の有無と正確な残ターン**を適用する。
- **同じ元の観測オブジェクトを変更しない**。同じ画面事実から各仮説ごとに複製・条件反映・正規化状態のハッシュ・完全なシリアライズ往復・同じ操作の合成継続を別々に試す。観測したHPが各仮説の最大HPより大きい場合はその候補を不適合として除く。
- **攻撃選択リクエスト境界**が観測できる場合のみ。残HP・相手の状態異常が未知、能力ランクが一部しか分からない、壁の残ターンが未知/矛盾、天候の履歴が必要、瀕死/強制交代、選択済みの未解決キュー、メガ履歴の不確実性等は`UNSUPPORTED`または従来のGate B未達として止める。
- どの候補も`hidden_set_origin=FIXED_LEGAL_HYPOTHESIS_NOT_GAME_OBSERVED`として扱う。実ゲーム側の完全な状態・内部RNG・未公開技を再現したという意味ではない。実機ソースのラベルが付いていても**出力は`PROVISIONAL_CONDITIONAL_SYNTHETIC`**、`gate_B=UNSUPPORTED`のまま。
- 結果をLIVE選出・確定KO・安全受け出し・勝率％として表示しない。実戦中のマスター再読込・ファイル調査も行わない。

### 試験項目

- 観測されたHP100とA+1（他の6能力ランク0）を4つの合法な仮説へ反映し、候補ごとのハッシュが独立・入力が不変・同条件の再実行が再現可能である。
- HP70とA+2、残り3ターンのリフレクターという**条件が既知の合成局面**を再現する。
- HP/能力ランクが未知または一部のみ、最大HP超過、瀕死、壁のターン不明・矛盾、未解決行動、天候、メガ後状態は不用意に初期値を採用せずフェイルクローズする。
- `SYNTHETIC`証拠の`GAME_OBSERVED`偽装は拒否。ゲーム観測ラベル付き入力も機械的な完全互換証明には昇格させない。

### 限界と次のGate B作業

これは**新しい合成条件付き枝の実装**であり、ゲーム中の任意タイミングのBattleを正しく復元できたわけではない。途中の相手被弾/行動・持ち物消費・メガ変化・残天候・壁継続の履歴、解決済みの技使用状態、未解決アクションキューとRNG分布は復元していない。未知値を推測で上書きしての「実戦使用」を禁止する。元画像とローカルGoldenはGitHub/CIに追加しない。

**次の優先課題**は、既存観測から履歴の整合を取れる範囲を増やし、仮説間の不変性と観測矛盾検出を定量化すること。その後、必要なChampions実機観測と照合し、採否はGate A/Bで独立判断する。Phase 1は依然NO_GO。
