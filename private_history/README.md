# 過去対戦履歴の取扱い（v2.7）

このディレクトリの `.xlsx` は、プロジェクトで共有された `Pokemon_Champions_battle_log` / `Pokemon_Champions_battle_data` の**バイト列を変更せず**、拡張子を付与して収録したものです。解釈済み・統合済み・整形済みのデータではありません。

- オフライン/試合後のみに読み込む。LIVE試合中のOCR/選出/技判断経路からアクセスしない。
- 既定でGit・Docker build context・CI成果物・外部共有に含めない。`../.gitignore` を確認する。
- APIに過去ログをまとめて送らない。試合後分析で送信が必要な場合は、利用者に明示・必要部分だけ・秘密/個人情報の除去を行う。
- ソースハッシュとシート名を保ち、元ワークブックを上書きしない。未知の列・不明な数値の意味は推測しない。
- ZIPをダウンロードしたり他者に渡したりすると、このディレクトリも含まれます。**ZIP自体を公開GitHubへアップロードしないでください。**
