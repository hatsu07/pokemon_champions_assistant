# Pokémon Champions 現環境データ取得元・運用ルール

## 目的
『Pokémon Champions（ポケモンチャンピオンズ）』シングル・ランクマッチの構築分析、選出分析、環境考察で使用する「動的な環境データ」の取得元と運用方法を固定する。

## 主取得元
- サイト: championsbattledata.com
- 公開ミラー: GitHub `Gheist23/pokemonbattledata`

## シングル統計データ
GitHub リポジトリ内:
`pokemon_champions_assets/battle_data/Singles/`

各ポケモンのCSVから以下を取得する。
- ポケモン使用率順位
- 技採用率ランキング
- 持ち物採用率ランキング
- 特性採用率ランキング
- 性格採用率ランキング
- 能力ポイント配分ランキング
- 必要に応じて、よく組まれるポケモン等の環境情報

## 取得ルール
1. 環境データは固定マスターとして常用せず、分析時に最新データを再取得する。
2. 取得時には、レギュレーションと取得日を明記する。
3. ポケモン本体の使用状況について、使用率%が公開されていない場合は順位のみを使用する。
4. 公開されていない使用率や採用率を推測で補完しない。
5. 技・持ち物・特性・性格・能力ポイント配分について採用率%が公開されている場合は、その値をそのまま使用する。
6. Pokémon Champions固有データを優先し、SV等の別作品の環境データを混在させない。
7. 公式情報と矛盾する場合は、公式情報を優先する。
8. 必要な場合のみ、日付＋レギュレーションを付けて環境スナップショットを保存する。
   例: `2026-09-29_Regulation_MC`


## ゲーム内ランキング情報の併用
- 必要に応じて、ユーザーが『Pokémon Champions』ゲーム内で確認できる使用率ランキングや関連情報を共有する運用とする。
- ゲーム内表示の情報がWeb上の集計データより新しい、または差異がある場合は、共有されたゲーム内情報を優先して現環境判断に使用する。
- ユーザーが共有したスクリーンショット・順位・採用率・型情報などは、その時点の最新環境スナップショットとして扱う。
- Webデータだけでは判断しにくい場合、必要な範囲に限ってゲーム内ランキング情報の共有を前提に分析する。
- ゲーム内情報とWeb上の統計に差がある場合は、取得時刻・更新タイミング・集計範囲の違いを考慮し、両者を混同せず明示する。

## 固定マスターとの役割分担
固定ファイルとして保持:
- 使用可能ポケモン
- 種族値
- タイプ
- 特性
- 特性マスター
- 使用可能持ち物
- 技マスター
- 各ポケモンのChampions習得技

都度取得:
- 使用率順位
- 技採用率
- 持ち物採用率
- 特性採用率
- 性格採用率
- 能力ポイント配分
- よく組まれるポケモン
- その他の最新環境傾向

## 運用方針
今後、ユーザーから「現環境」「今の型」「使用率上位」「この構築が環境に刺さるか」等の質問があった場合、
まず上記取得元から最新のシングル統計を確認した上で回答する。
