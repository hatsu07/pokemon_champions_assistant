# 構築別LIVEマトリクス／ルックアップとSingles環境データ

## 使い方

1. **設定 → 自軍構築** で現在ゲーム内で使う6匹と全4技、持ち物、特性、性格、能力配分を登録・保存。
2. **次戦に選択** → 設定画面下の **保存**。保存時に構築固有のマトリクス／60秒ルックアップをローカル作成・キャッシュする。
3. **対戦開始（4ファイル事前読込）**。選択構築、対応マトリクス、対応ルックアップ、共通LIVE判断ゲートの **4本文** をその試合で実読込・固定する。対戦開始後は再生成・Web参照しない。
4. 環境統計を新しくする場合のみ、**対戦前**に **シングル環境データを更新** を押す（バックグラウンド通信）。取得失敗なら前回の正常スナップショットを維持。 **ゲーム内統計JSONを取り込む** では同じJSONスキーマのプレイヤー確認情報を取り込む。
5. 勝敗が実画面で観測されると、必要最低限の試合記録を端末内に追記する。人間戦／CPU不明の推定や戦術評価の自動採用はしない。

## 「生成済み」と「実戦評価済み」は異なる

元のLIVEマトリクスは、2026-10-03構築の6匹専用に作られた358行の評価であり、異なる6匹に単純コピーできない。

- **REVIEWED_REUSE**：6枠とも元の評価対象と **同じポケモン・4技・持ち物・特性・性格・配分・関連状態** で一致した。順番違いは列を並べ替えて再利用できる。構築対応として扱い、元の戦術評価そのものが完全無欠であるという意味ではない。
- **PROVISIONAL_UNVERIFIED**：型の異なる枠は `?,?,?,?,U,0` として未検証、`??` で最初の行動を未確定とし、処理役／安全受けへ**昇格しない**。相手ポケモン358行・相手側の警戒候補は保持。データの構造は作成されるが、`matrix_compatible=false`として実戦用戦術評価・18対面PREPが不可能であることをユーザーに示す。決してREADYと偽称しない。
- 明確な処理役、安全な受け先、新しい構築に対する高期待値の選出を評価するには、Champions専用の実際の検証済み対面データが別途必要。**公開の使用率統計から確1・受け安全・型確定を捏造しない。**

元の`masters/`は変更せず、プライベートの`<storage.data_root>/live-team-assets/<team_id>/<fingerprint>/matrix.txt`と`lookup.txt`、監査用`manifest.json`へ保存する。構築の実データ、元の両マスター、環境スナップショットのSHAに応じて別キャッシュへ保存し、同じ入力なら再利用する。各ファイルのSHAはmanifestにも記録。Gitや配布ZIPには同梱しない。

## Battle data 収集・更新と出典の扱い

- 公開SinglesのURL：`https://raw.githubusercontent.com/Gheist23/pokemonbattledata/main/data/builder/meta-singles.json`（`championsbattledata.com`の公開GitHubミラー）。
- 更新は利用者が明示操作した場合のみ。8MiB上限、12秒タイムアウト、`format=Singles`、名称重複・順位・採用率の範囲を検証。
- `<storage.data_root>/battle-evidence/singles-usage.json` に統計本文、`singles-provenance.json`に**取得時刻・元データ生成時刻・出典URL・データSHA・単独/ダブル区分**を保存。公開元がレギュレーションを明記しない場合は `UNDECLARED_BY_SOURCE` とする。登録チームのレギュレーションを統計出典のレギュレーションと捏造して一致させない。
- 公開データとプレイヤー確認のゲーム内データは`source_kind`で区別。ゲーム内の最新情報が優先だが、データソースの更新・収集日も確認する必要がある。
- 勝敗確認後のみ`observed-matches.jsonl`へ1試合1行。これは**AIによる画面判定結果・未確認**という出典付きの自動収集であり、誤分類・CPU混入などを排除した正式統計ではない。技固定や安全受けの教師ラベルには自動昇格しない。
- 機械に存在するポケモン能力値・技定義・習得、持ち物、特性は別のChampions固定マスターが正本。使用率は相手の型確定ではない。SVやZAなど他作品で埋めない。

## 注意事項と未実装

**現在の仕組みは、元の構築と異なる型・ポケモンに対する対面評価の自動生成までは完成していません。** 正確な新規対面評価を作るためのChampions専用ダメージ検証、対面データのレビュー・承認UI、環境統計から試合状況別の対面処理役の確定は将来課題です。「構築を選択しただけで高勝率の完成マトリクスが得られる」という保証はありません。

外部サイトのschema/アクセスが変わる場合、更新に失敗しますが従来のマスターは破損しません。対戦中の通信・再学習は禁止。ダウンロード・マスター読込、キャッシュ生成は**次戦準備時**だけ。保存済みプライベートデータと元のLIVEマスターは上書きしません。
