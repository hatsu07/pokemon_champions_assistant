# 構築別の自動ChatGPT対面分析（開発版）

## 現在の運用
「設定 → 自軍構築」で構築を選択し、「構築別対面を自動解析（最大180回・試合前）」を**一度だけ明示操作**すると、未評価対面を12件ずつ連続してChatGPTに送り、構築・マスター・レギュレーションの整合性を確認しながら提案をプライベートなローカルデータとして保存する。

- 既に解析済みの対面は再送せず、途中で停止しても完了済み分を保持。再開は同じボタンを使う。
- 最大180件のAPIリクエスト（各最大12対面）を1回の操作で行えるが、モデルの利用枠・API応答時間・ネットワーク状況に依存する。中断は現在のAPIリクエスト完了後に反映する。
- 操作前に通信回数・利用枠に関する同意を得る。アプリ起動時・試合中に自動送信しない。画像や対戦ログは本分析のAPIリクエストには添付しない。
- AIの対面提案は引き続き `AI_PROPOSAL_UNVERIFIED` として扱う。推定KO・想定S順・処理役・安全受けを確定するデータには昇格させない。
- 既存の `358×6` カタログと構築別のマトリクス・ルックアップを引き続き生成・キャッシュする。計算不能な対面は `UNKNOWN`、新構築は `PROVISIONAL_UNVERIFIED` のまま。AI提案文はLIVEマトリクスに直接書き込まない。
- **Championsの技マスター・習得技マスターから直接確認できる「相手が習得可能な優先度プラスの技」だけ**、構築別LIVEマトリクスと60秒ルックアップの警戒欄に補助情報として反映する。相手の実際の採用技・先制で倒せるか・安全に受けられるかを保証しない。

## 廃止したGUIフロー
前バージョンの「AI対面候補を実機証拠で確認・承認（条件付きLIVE注記）」ボタンとレビューJSON取込ボタンは、通常の自軍構築設定画面から外した。利用者に対面ごとの手動ファイル選択・個別承認は求めない。過去の証拠付き人間レビューの保存データは破壊・削除しない。

## 継続課題
Champions固有の検証済みダメージ・素早さ計算エンジン、実戦観測の自動化と妥当性検証、選出90秒／PREP40秒／各ターン45秒の実機検証は未完成。多数のAI提案が保存されても `CONFIRMED` 件数は増えない。未検証の技・特性・対面を他作品の知識で穴埋めしない。

これらの制限は長期勝率を優先した安全策であり、ChatGPT推測を根拠に誤った処理役・安全受けをLIVE認定しない。
