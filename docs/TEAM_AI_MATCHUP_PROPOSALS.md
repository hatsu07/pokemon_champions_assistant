# 構築別の自動ChatGPT対面分析（開発版）

## 現在の運用
「設定 → 自軍構築」で構築を選択し、「構築別対面を自動解析（最大180回・試合前）」を**一度だけ明示操作**すると、未評価対面を12件ずつ連続してChatGPTに送り、構築・マスター・レギュレーションの整合性を確認しながら提案をプライベートなローカルデータとして保存する。

- 既に解析済みの対面は再送せず、途中で停止しても完了済み分を保持。再開は同じボタンを使う。
- 最大180件のAPIリクエスト（各最大12対面）を1回の操作で行えるが、モデルの利用枠・API応答時間・ネットワーク状況に依存する。中断は現在のAPIリクエスト完了後に反映する。
- 操作前に通信回数・利用枠に関する同意を得る。アプリ起動時・試合中に自動送信しない。画像や対戦ログは本分析のAPIリクエストには添付しない。
- AIの対面提案は引き続き `AI_PROPOSAL_UNVERIFIED` として扱う。推定KO・想定S順・処理役・安全受けを確定するデータには昇格させない。
- 既存の `358×6` カタログと構築別のマトリクス・ルックアップを引き続き生成・キャッシュする。計算不能な対面は `UNKNOWN`、新構築は `PROVISIONAL_UNVERIFIED` のまま。AI提案文はLIVEマトリクスに直接書き込まない。
- **Championsの技マスター・習得技マスターから直接確認できる「相手が習得可能な優先度プラスの技」だけ**、構築別LIVEマトリクスと60秒ルックアップの警戒欄に補助情報として反映する。相手の実際の採用技・先制で倒せるか・安全に受けられるかを保証しない。

## 廃止したGUIフロー
前バージョンの「AI対面候補を実機証拠で確認・承認（条件付きLIVE注記）」ボタンとレビューJSON取込ボタンは、通常の自軍構築設定画面から外した。利用者に対面ごとの手動ファイル選択・個別承認は求めない。過去の証拠付き人間レビューの保存データは破壊・削除しない。

## 継続課題
Champions固有の検証済みダメージ・素早さ計算エンジン、実戦観測の自動化と妥当性検証、選出90秒／PREP40秒／各ターン45秒の実機検証は未完成。多数のAI提案が保存されても `CONFIRMED` 件数は増えない。未検証の技・特性・対面を他作品の知識で穴埋めしない。

これらの制限は長期勝率を優先した安全策であり、ChatGPT推測を根拠に誤った処理役・安全受けをLIVE認定しない。


## 根拠限定のAI戦術支援（構築別暫定マトリクス）
全358×6対面を実戦で検証しなければ使えない、という運用にはしない。
Champions専用固定マスター・登録済み自軍の4技/持ち物/特性/AP・レギュレーションと、試合前に取得したSinglesの公開使用率候補を根拠として、ChatGPTが「相手6匹の選出」「選出3×相手6の18対面」「ターンごとの合法な行動」を**不確実性を残した条件付きの提案**として作成する。公開シーズン情報の例は `https://champions-news.pokemon-home.com/ja/page/845.html` （M-7・M-C、2026-10-25確認時点）。公開使用率は `src/champions_assist/environment_refresh.py` の指定済みChampions Singlesプロバイダーから**試合前のみ**取得する。取得できない場合は直前の正常なスナップショットを利用し、相手ゲーム内データの方が新しい場合はそれを保持する。

- 別構築のLIVEマトリクスは利用不可のまま。**生成器の `# TEAM_SCOPED_MATRIX` / `# PROVENANCE` / `# DERIVED_STATUS=PROVISIONAL_UNVERIFIED` と自軍6匹の順序一致**を確認できた場合だけ、`PROVISIONAL_ADVICE` を許可する。通常の `matrix_compatible`、`live_ready` は**引き続きFalse**。
- 選出のときに事前ロード済みマトリクスから相手6行を使用し、18対面PREPを構造上評価する。先頭の `?` や `UNKNOWN` をダメージ・S関係・確定処理役・安全な受け先に変換しない。PREPは `PREP_PROVISIONAL`（構造検証のみ）と表示。
- ターンでは観測した技・行動順・HP・道具・特性を優先し、合法な表示技・交代先に限定して `PROVISIONAL_ADVICE` を提示する。相手の隠れた4技や型を使用率から確定せず、処理役と安全受けを区別する。
- **Web検索を対戦中には行わない。** 対戦前に取得・凍結したデータと既存の4ファイルを利用する。外部プロバイダー由来の技・持ち物・特性・使用率は「採用候補」であり、ゲーム内観測に優越しない。Champions固定マスターにない技効果、確定ダメージ、S・メガ後能力は他作品で埋めない。
- 以前の実戦認定・命中率・勝率を保証しない。このモードは実際のBlueStacks環境で選出90秒/40秒PREP/45秒ターンの期限を検証するまで **開発版の暫定戦術支援**。安全性より過度に消極的な `NO_ACTION` に逃げず、比較できる範囲の具体的行動をAIが選ぶが、根拠不足で合法手も定まらない場合は推奨不可とする。
- 全2,148対面への一括ChatGPT分析は任意。実際の相手6匹が判明した後の18対面推論の代用とはせず、費用・時間がかかる一括API解析を**実戦支援の前提条件にはしない**。
