# 構築別ChatGPT対面分析候補（開発版）

## 機能
「設定 → 自軍構築」で構築を保存し選択したあと「ChatGPTで未評価対面12件を分析（対戦前・未検証候補）」を明示操作する。選択済みのChatGPTモデルと既存のDPAPI保護ログインで、固定マスター由来の未評価セル（最大12件）のみを送り、構造化された条件付き戦術候補を受信する。画像・対戦ログ・認証情報はプロンプトに入れない。繰り返し操作で同一構築・同一根拠スナップショット内の保存済み候補を省略する。

結果はプライベートデータ `<data_root>/live-team-assets/<team_id>/<fingerprint>/ai-proposal-<uuid>.json` に **AI_PROPOSAL_UNVERIFIED** として保存。元カタログSHAが解析中に変化した場合は保存を拒否。AIの返答で相手の型・確定KO・処理役・安全受けを確定しない。

**重要**: AI候補はLIVEマトリクスや60秒ルックアップには自動反映しない。実装済みの `PROVISIONAL_UNVERIFIED` 状態と試合中の4ファイル読込制限を維持する。完成した構築専用評価エンジン、Champions固有ダメージエンジン、実戦認定ではない。既存の承認済み評価入力や別途の対面検証が必要。

## 安全性と費用
ChatGPTログイン済みで利用可能なモデルを「ChatGPT」タブから指定する。送信前にダイアログで明示同意を求め、対戦中には開始しない。ネットワークは専用QThreadで実行し、終了まで設定を閉じない。エラー時は既存のマトリクスを変更しない。外部接続と実機ゲームでの検証は未実施で、利用可能なモデル・プランおよびネットワーク環境に依存する。

## 続く作業
Champions固有の検証済み数値エンジン・実機対面証拠を導入し、AI候補を人間が点検してマトリクスへ取り込める承認フローを作成する。構築変更に関係する列だけを再評価する。未検証候補の自動昇格、モデルのみを根拠とした処理役・受け安全の昇格は禁止する。

## 人間によるレビュー・LIVE注記（次段階の実装）

「設定 → 自軍構築」で対象を選び、ChatGPTで対面分析を実行した後、**「AI対面候補を実機証拠で確認・承認（条件付きLIVE注記）」**を押します。保存済みの候補から1対面を選び、AIの評価案を参考情報として閲覧し、別途実際にゲーム内で確認した事実を自分の文章で記載します。ゲーム画面画像（PNG/JPEG）または実機記録JSONを根拠として選択し、最終確認で承認します。

- 1件の根拠：**CONDITIONAL**（条件付きの観測記録）。2件の異なる根拠と実測した相手の技を入力した場合：**CONFIRMED**（2件の観測根拠があるというレビュー区分）。どちらも**対面で安全・確実に勝てるという認定ではありません**。
- UIで選択した根拠ファイルは**SHA-256だけ**をレビュー記録へ保存します。画像自体はアプリからChatGPT、GitHub、公開リリースへアップロードしません。AI候補ファイルそのものを実機根拠として使うことは拒否します。
- 現在の6匹の型シグネチャ・レギュレーション・Champions固定マスターのSHAが一致するAI候補だけがレビュー対象です。古い構築の提案は拒否します。既存の有効な人間レビューは保存したまま、対象セルだけ更新します。
- 承認後、次戦用に生成される **matrix.txt と lookup.txt の相手行「警戒」列**へ「人間確認(A:条件付観測;処理受け未認定)」などの固定文言を反映します。具体的なAI文章やユーザー自由文はLIVE本文へ挿入しません。レビュー済み観測は `manifest.json` の `live_observation_markers` で数えられます。
- **重要：各セルのレート・処理役・受け安全・実測最大打点・S関係は未検証のままです。** 観測2件でも実機上の全ての相手型、交代時最大打点、特性・道具・メガ等を保証しません。 `PROVISIONAL_UNVERIFIED` と選出/PREPの非対応状態はそのまま維持します。したがって、承認された対面の警戒メモがLIVEに出るだけで、実戦で勝てる完成版マトリクスになったわけではありません。
- 画像やJSONのSHAだけでは内容を機械的に真偽検証できません。人間の最終確認が必要です。ゲーム画面からの自動事実認識・Champions固有ダメージ/S計算エンジン・安全受け認定はまだ別工程です。

**検証手順（試合前のみ）**：`test` 構築で「AI未評価対面分析」→「AI対面候補を実機証拠で確認・承認」→「構築別358×6対面根拠JSONを確認」を実行して `CONDITIONAL` / `CONFIRMED` の増加を確認し、プライベートな `matrix.txt` と `lookup.txt` に対応する観測マーカーが現れることを確認してください。対戦開始後は生成やネットワーク参照を行いません。
