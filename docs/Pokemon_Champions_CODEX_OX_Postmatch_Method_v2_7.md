# CODEX O / X 試合後分析ガイド（プロジェクト指針の再構成）v2.7

## 適用範囲
- **対戦後分析専用**。選出90秒・40秒PREP・各ターン45秒のLIVE判断に新しいO/X計算を組み込まない。
- O/Xの採点や重みの固定値は未検証。スカラー化を強制せず、判断の質を言語化する補助ラベルとする。
- 常に「その時点で観測されていた情報のみ」を使い、事後判明した相手型から当時の最適解を断定しない。

## O（選択肢の優位性）
- 双方の有効な選択肢、相手の勝ち筋の制限、一手先だけでなく技固定・交代順・相手残りへの一貫性を比較。
- 例：この場で倒せるか、控えに安全に交代できるか、相手の積みエースを止められるか、終盤役を温存できるか。
- 比較対象は実行できる合法択だけ。「処理できる」ことと「安全に着地できる」ことを混同しない。

## X（実行の安定性）
- 勝ちまでの工程の多さ、成功条件、命中・追加効果・読み依存、行動保証の消費、複数ターンの成功確率を分析。
- 目先の被害が少ないだけの延命を高評価しない。最終的にHP0へ到達するルートが必要。

## 改善候補の運用フロー
1. 当時の見えていた情報・判断・結果・不確実性を再構成。
2. **まず既存 `Pokemon_Champions_MC_live_decision_gate.txt` によって防げたミスか確認**。防げたなら「既存ルール実行ミス」と記録して、新ルールは追加しない。
3. 防げなかった場合だけ `OX_CANDIDATE` として候補化。別候補（安全択/期待値択/読み択/負け筋）との比較を残す。
4. 同条件・類似複数試合・必要なChampions固有数値で改善効果を検証。未検証なら `HOLD`。
5. 改善確認済みの候補のみ、判断時間・重複・実戦有効性を審査し `ADOPTED` または `HOLD/REJECTED` を記録。
6. 採用時もLIVE判断ゲートの唯一正本を維持し、マスター改版とテストを伴う。元ファイルを無断上書きしない。
