# GUI設定 v2.8 利用手順

この画面は既存の **Pokémon Champions Assistant** デスクトップの「設定」ボタンから開きます。設定操作、プレビュー、CSV登録はOpenAI APIを送信せず、ゲームへの入力も行いません。

## 起動

開発時のDocker/offscreen確認は次のとおりです。画面は表示せず、モックだけを使います。

```bash
docker compose run --rm -e QT_QPA_PLATFORM=offscreen dev \
  python -m champions_assist desktop-demo --master-dir masters --offscreen
```

通常配布用のWindows PyInstaller/MSIはPhase 7の未完了項目です。開発用PythonをWindowsへ入れず、設定・読取プレビューだけを実機確認するポータブル検証成果物は用意しています。手順は[Windows 実機: GUI設定・読取プレビュー検証](Windows_Real_Hardware_Settings_Validation.md)を参照してください。この成果物はMSI・正式配布版・連続観測の実機合格ではありません。

## 初回設定と保存場所

Windows実行時の既定の非秘密設定は、`%LOCALAPPDATA%\PokemonChampionsAssistant\config\settings.json` です。初回は設定ダイアログが開きます。

- `対戦データ/SQLite/診断ログ` と `キャプチャ/較正画像` はフォルダー選択で指定します。
- 保存時に、フォルダー作成、書込み試験、空き容量を確認します。
- 保存先の移行はコピー後に全ファイルのサイズとSHA-256を照合し、旧データは削除しません。移行先が空でない場合は停止します。
- 試合中の保存先変更は予約され、次戦開始前にだけ反映します。
- SQLite保存先を切り替えた次戦では、旧DBに接続したAPIワーカーを安全のため停止します。APIを再開するにはアプリを再起動して新しい保存先へワーカーを結び直してください。
- 設定JSONにAPIキー、トークン、パスワードなどは保存しません。破損時は直前の`.bak`を読み、それも使えなければ既定値へ安全に戻します。

対戦ログ、構築CSV、画像、SQLiteはユーザーデータとして扱います。Git、GitHub Actions成果物、MSIへ追加しないでください。

## 画面キャプチャ

1. `設定` → `画面キャプチャ` で `ウィンドウを検索` を押します。
2. BlueStacks候補は上位に表示されますが、タイトル、PID、HWNDを持つ選択肢から明示的に選びます。
3. `動作確認` で読み取り専用の1フレームプレビューを取得します。表示する解像度、Win32 DPI、取得時間は診断値であり、ゲーム内容の認識成功を意味しません。
4. プレビュー上でゲーム領域をドラッグすると**ドラッグ途中から矩形を表示**し、離すとROIを確定します。矩形内のドラッグで移動、四隅・辺のハンドルで拡大縮小できます。下の左・上・右・下のpx欄でも境界を調整でき、プレビューにフォーカスした状態の矢印キーで1px、Shift+矢印で10px動かせます。既存の保存値は正規化ROIのままです。画像が未取得の間、px欄は無効になります。ウィンドウサイズ/DPIが変わった場合は再較正してください。
5. 必要な場合のみ `テスト撮影を保存` を押します。既存ファイルは上書きしません。

対象ウィンドウが消失、再生成、最小化、または取得に失敗したときは停止して警告します。デスクトップ全体へ黙って切り替えません。対戦中にキャプチャ対象を保存変更した場合は、既存のAI回答を緊急停止相当で無効化します。観測ワーカーの実機再同期はまだ未検証です。

ADBは明示したローカル実行ファイルとserialだけを使う代替です。実装する操作は`get-state`と`exec-out screencap -p`の読み取りだけで、`adb input`、tap、keyevent、接続設定、ポート転送は行いません。

## 自軍構築

1. `自軍構築` → `CSVを登録` から現在の`Pokemon_Champions_MC_team_2026-10-03.csv`を選びます。
2. `TEAM` 1行と`MON` 6行、各4技を読み、未知列やTEAM行の補足も保持します。
3. 一覧から構築を選び、6匹の表を編集して`編集した構築CSVを保存`、または`CSVをエクスポート`します。
4. `次戦に選択`してから設定を保存します。

登録時は、同梱のChampions固定マスターにあるポケモン、技、持ち物、特性、確認済み習得技だけを照合します。Unicode表記差は比較時だけ正規化し、CSV原文は変更しません。AP配分・性格など固定マスターに根拠がない項目は`NEEDS_REVIEW`のままです。`INVALID`または`SOURCE_MISSING`は次戦に選択できません。別作品の知識による補完は行いません。

構築・保存先の変更は試合中には予約されます。次の`次戦を開始`時に、LIVE判断ゲート、LIVE選出マトリクス、60秒ルックアップ、選択構築CSVの4ファイルを新規に読み、SHA-256を固定します。前試合の状態、PREP、送信済み入力は変更しません。
